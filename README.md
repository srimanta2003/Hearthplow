# 🌾 Hearthplow

### Experience the World of Farming Through Interactive Gameplay

**Hearthplow** is an interactive agriculture-themed game designed to bring the experience of farming and field cultivation into a digital environment. Players explore farming activities, operate agricultural machinery, and experience the process of preparing land for cultivation.

The project combines modern web technologies with interactive visual experiences to create an engaging farming simulation.

---

## 🎮 About the Project

Hearthplow aims to provide an enjoyable and interactive farming experience where players can explore agricultural activities, understand the importance of land preparation, and engage with farming-inspired gameplay.

From preparing fields to operating farming equipment, the game focuses on bringing agricultural concepts into an accessible digital experience.

## ✨ Key Features

- 🚜 **Farming Experience** – Explore agriculture-inspired gameplay.
- 🌱 **Field Cultivation** – Experience the process of preparing land for farming.
- 🎮 **Interactive Gameplay** – Engage with an interactive gaming environment.
- 🌍 **Visual Experience** – Modern graphics and interactive elements.
- 🏆 **Task-Based Gameplay** – Experience farming challenges and objectives.

## ⚙️ Installation & Setup

Follow these steps to run Hearthplow locally.

### 1. Clone the Repository

```bash
git clone https://github.com/srimanta2003/Hearthplow.git
```

### 2. Navigate to the Project

```bash
cd Hearthplow
```

### 3. Install Dependencies

Using Bun:

```bash
bun install
```

Alternatively, using npm:

```bash
npm install
```

### 4. Configure Environment Variables

Create your environment configuration using the provided example:

```bash
cp .env.example .env
```

Add the required API keys and configuration values if the application requires them.

### 5. Start the Development Server

Using Bun:

```bash
bun run dev
```

Or using npm:

```bash
npm run dev
```

Open the local URL displayed in your terminal to access the application.

## 🏗️ Build for Production

To generate an optimized production build:

```bash
bun run build
```

To preview the production build:

```bash
bun run preview
```
